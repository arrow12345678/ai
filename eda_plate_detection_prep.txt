### 3. Annotation Preparation (YOLO Format)

YOLO models require annotations in a specific format: a `.txt` file per image, with each line representing an object: `<class_id> <x_center_norm> <y_center_norm> <width_norm> <height_norm>`.

*   `<class_id>`: Integer for the object class (e.g., 0 for 'license_plate').
*   `<x_center_norm>`: Normalized x-coordinate of the bounding box center (`box_center_x / image_width`).
*   `<y_center_norm>`: Normalized y-coordinate of the bounding box center (`box_center_y / image_height`).
*   `<width_norm>`: Normalized width of the bounding box (`box_width / image_width`).
*   `<height_norm>`: Normalized height of the bounding box (`box_height / image_height`).

All normalized values are floats between 0 and 1.

```python
def convert_bbox_to_yolo(bbox_abs, image_width, image_height, class_id=0):
    """
    Converts an absolute bounding box [xmin, ymin, xmax, ymax] to YOLO format.

    Args:
        bbox_abs (list or tuple): [xmin, ymin, xmax, ymax] in absolute pixel values.
        image_width (int): Width of the image.
        image_height (int): Height of the image.
        class_id (int): Class ID for the object.

    Returns:
        list: [class_id, x_center_norm, y_center_norm, width_norm, height_norm]
    """
    xmin, ymin, xmax, ymax = bbox_abs

    dw = 1.0 / image_width
    dh = 1.0 / image_height

    x_center = (xmin + xmax) / 2.0
    y_center = (ymin + ymax) / 2.0
    width = xmax - xmin
    height = ymax - ymin

    x_center_norm = x_center * dw
    y_center_norm = y_center * dh
    width_norm = width * dw
    height_norm = height * dh

    return [class_id, x_center_norm, y_center_norm, width_norm, height_norm]
```

### 4. Data Augmentation

Data augmentation artificially increases dataset size and diversity, helping models generalize better and reduce overfitting. It is applied **only to the training set**.

*   **Libraries:** `Albumentations` is a popular library for image augmentation, especially for object detection tasks as it handles bounding box adjustments. TensorFlow (`tf.image`) and Keras (`keras.layers.Random...`) also provide augmentation tools.

*   **Common Techniques for LPR Detection:**
    *   Random Brightness/Contrast adjustments
    *   Random Rotation (small angles)
    *   Horizontal Flip (if license plates are generally symmetrical or if mirrored plates are possible/acceptable)
    *   Motion Blur, Gaussian Blur
    *   Random Noise (e.g., Gaussian noise)
    *   Random Scaling (zoom in/out)
    *   Minor perspective shifts
    *   **Cropping (with caution):** Random cropping might cut off parts of the license plate. If used, ensure the plate remains largely intact (e.g., "RandomSizedBBoxSafeCrop" in Albumentations).

### 4. Data Augmentation

Data augmentation artificially increases dataset size and diversity, helping models generalize better and reduce overfitting. It is applied **only to the training set**.

*   **Libraries:** `Albumentations` is a popular library for image augmentation, especially for object detection tasks as it handles bounding box adjustments. TensorFlow (`tf.image`) and Keras (`keras.layers.Random...`) also provide augmentation tools.

*   **Common Techniques for LPR Detection:**
    *   Random Brightness/Contrast adjustments
    *   Random Rotation (small angles)
    *   Horizontal Flip (if license plates are generally symmetrical or if mirrored plates are possible/acceptable)
    *   Motion Blur, Gaussian Blur
    *   Random Noise (e.g., Gaussian noise)
    *   Random Scaling (zoom in/out)
    *   Minor perspective shifts
    *   **Cropping (with caution):** Random cropping might cut off parts of the license plate. If used, ensure the plate remains largely intact (e.g., "RandomSizedBBoxSafeCrop" in Albumentations).

**Important:** Ensure that bounding box coordinates are correctly transformed when augmentations like rotation, cropping, or resizing are applied. Libraries like `Albumentations` handle this automatically when configured correctly with `bbox_params`. The `min_visibility` and `min_area` parameters in `BboxParams` are crucial for ensuring that augmented bounding boxes still meaningfully represent the object.
